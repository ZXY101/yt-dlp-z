# yt-dlp-z documentation

yt-dlp-z is a self-hosted web dashboard for [yt-dlp](https://github.com/yt-dlp/yt-dlp).
Start with [Installation](installation.md), then read the guides for the
features you use.

## Getting started

- [Installation](installation.md): Docker, without Docker, first-run setup,
  reverse proxies, updating, backups

## Using yt-dlp-z

- [Downloads](downloads.md): the download form, link check, playlists, every
  yt-dlp option, the queue
- [Presets](presets.md): reusable option sets, kinds of presets and defaults
- [Subscriptions](subscriptions.md): watching YouTube channels and playlists
- [Live recording](live-recording.md): recording live and scheduled streams,
  24/7 streams, VODs
- [Cookies](cookies.md): members-only, private and age-restricted videos
